# Minify

A minimal yet powerful URL shortener built using **React + Vite & TailwindCSS** on the frontend and connected to an API endpoint created by **Frontend Mentors** that allows users to shorten long, clunky URLs into clean, shareable links. Minify is designed to reduce link fatigue in daily tech conversations, make sharing easier, and improve user experience across platforms.

## 🚀 Why Minify?

Have you ever tried sending a long, messy URL in a group chat, DM, or document? Minify helps solve that by:

- Transforming long URLs into short, readable ones
- Providing instant copy-to-clipboard functionality
- Saving recently shortened links using browser localStorage
- Offering future expandability like QR code generation, analytics, and expiration control

Minify is built with the philosophy of reducing stress and simplifying digital life—one feature at a time.


## 🧰 Tech Stack

- **Frontend:** React + Vite
- **Styling:** Tailwind CSS (optional), plain CSS fallback
- **API:** Integrated with [CleanURI]from Frontend Mentors **(https://www.frontendmentor.io//)** for URL shortening
- **State & Storage:** useState, localStorage
- **Deployment:** Vercel For Beta Testing, and Hostinger For Production after all viable checks


## 🛠️ How to Use / Run Locally

1. **Clone the repository**

```bash
git clone https://github.com/kngDaveed/minify
cd minify
````

2. **Install dependencies**

```bash
npm install
```

3. **Run the development server**

```bash
npm run dev
```

4. **Visit the app**

Navigate to `http://localhost:5173` in your browser.

## 🧑‍💻 Developer Experience

This project uses [Vite](https://vitejs.dev/) to provide fast development startup, Hot Module Reloading (HMR), and minimal configuration.

It supports:

* Easy environment variable setup via `.env`
* Modular React components
* Clean abstraction with `useApi.js` for handling API calls
* Extendable structure for analytics, QR generation, and admin tools on Updates
